# Daily Workouts 🚀

A dedicated workspace for daily coding practice, algorithmic growth, and experiments with Generative AI. This repository documents my commitment to consistency and technical exploration.

## 🎯 Purpose
To maintain daily engineering habits by:
* Solving algorithmic challenges (Python).
* Exploring and refining GenAI workflows (LangGraph, Bedrock, etc.).
* Building a searchable knowledge base of technical solutions.

## 🛠 Tech Stack
* **Language:** Python
* **AI/LLM:** LangGraph, Amazon Bedrock, Prompt Engineering
* **Practice:** HackerRank / LeetCode Solutions

## 📂 Structure
- `algorithms/`: Daily solutions organized by topic/date.
- `gen-ai-labs/`: Small experiments, prompt chains, and agentic workflows.

## 💡 Engineering Philosophy
I believe in "AI-assisted" over "AI-generated." Every piece of code here is reviewed, tested, and optimized. I focus on understanding the *why* behind the code, ensuring that AI output is treated as a draft for professional refinement.
